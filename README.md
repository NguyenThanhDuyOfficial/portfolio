## Getting Started

### Prerequisites

- pnpm
  ```sh
  npm install pnpm@latest -g
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/NguyenThanhDuyOfficial/portfolio.git
   ```
2. Install NPM packages
   ```sh
   pnpm install
   ```
3. Enter your API in .env
   ```sh
   cp .env.example .env
   ```
4. Start the server
   ```sh
   pnpm dev
   ```

The web is available at http://localhost:3000
